# 01_BRAND_GINAS_BEAUTY

## 목적
**지나스 뷰티(GINAS BEAUTY)** 브랜드 전용 폴더입니다.
뷰티 제품·콘텐츠·고객 커뮤니케이션에 관한 모든 자료를 보관하며, 뷰티 고유의 감성적·신뢰 기반 화법을 유지합니다.

> 🚫 **도메인 분리 원칙:** 이 폴더에는 BrandG AI 사업(02), 운명PT(03) 문법을 섞지 않습니다.
> 뷰티 화법과 AI 사업 화법은 서로 다른 언어 체계입니다.

## 저장할 자료
- `BRAND_GRAMMAR.md` — 뷰티 전용 문법(감성 키워드, 금지 표현, 표현 톤)
- `PRODUCT_NOTES/` — 제품 라인업·콘셉트·USP 정리
- `CONTENT/` — 상세페이지, SNS, 광고 카피 초안
- `CUSTOMER_VOICE.md` — 고객 후기·반응 패턴 (개인정보 제거 후 요약만)
- `CHANNEL_STRATEGY.md` — 판매/노출 채널 전략

## 사용 예시
- 신제품 상세페이지 작성 → `BRAND_GRAMMAR.md` 기준으로 카피 생성
- 인스타 릴스 기획 → `CONTENT/`에 후크·스크립트 저장
- 광고 심의 리스크 점검 → 뷰티 광고 금지 표현 체크

## 분리 원칙
- 화장품 표시·광고 관련 **과장/의학적 효능 표현 금지** 가이드를 항상 우선합니다.
- AI/자동화 관련 내용은 절대 여기 두지 않고 `02_BRANDG_AI`로 보냅니다.
