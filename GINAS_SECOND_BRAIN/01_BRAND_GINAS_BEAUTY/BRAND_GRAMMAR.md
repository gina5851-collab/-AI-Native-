# BRAND_GRAMMAR.md — 지나스 뷰티 브랜드 문법

지나스 뷰티(GINAS BEAUTY) 전용 화법·표현 규칙입니다. 모든 뷰티 콘텐츠는 이 문서를 기준으로 작성·검수합니다.

> 🚫 이 문법은 **뷰티 전용**. BrandG AI(02)·운명PT(03)·무비지나(04) 문법과 섞지 않습니다.

---

## 1. 말투 / 톤
- **부드럽고 신뢰감 있는 감성체.** 친근하되 가볍지 않게.
- 사용자를 가르치지 않고 **함께 경험을 나누는** 어조.
- 1인칭("제가 써보니")·공감("이런 고민 있으셨죠") 활용 가능.
- 감탄·이모지는 절제해서 포인트로만(남용 금지).
- 피부·사용감 등 **체험 묘사** 중심. 문장은 짧고 호흡 있게.

## 2. 금지어 / 금지 표현 + 이유
> 화장품은 의약품이 아니므로, **의료·치료·시술처럼 보이는 표현**은 법적 리스크이자 소비자 오인 유발입니다.

| 금지 표현 | 왜 금지인가 |
|-----------|-------------|
| 치료 / 완치 / 낫는다 | 의약품 효능 표방 → 화장품 표시·광고 위반 |
| 재생 / 세포 재생 / 회복 | 의학적 작용 암시 → 효능 오인 |
| 주름이 사라진다 / 없애준다 | 효과 단정 → 과장광고 |
| 시술급 / 리프팅 효과 / 보톡스 같은 | 의료 시술 효과 오인 |
| 여드름·아토피가 낫는다 | 질병 치료 표방 → 위반 |
| 100% / 무조건 / 부작용 없음 | 절대·과장 표현 → 신뢰 훼손·법 위반 |
| 최고 / 유일한 | 객관적 근거 없는 최상급 → 비교광고 리스크 |
| (경쟁사 직접 비방) | 비방광고 |
| 안 쓰면 늙는다 식 | 불안·공포 조장 마케팅 |

### 대체 표현 (Before → After)
| ❌ 금지 표현 | ✅ 대체 표현 |
|-------------|-------------|
| 주름을 없애준다 | 탄력 있어 보이는 피부 표현을 도와줘요 |
| 피부를 재생시킨다 | 피부 결을 매끈하게 가꾸는 데 도움을 줄 수 있어요 |
| 여드름을 치료한다 | 번들거림 없이 산뜻한 피부 관리를 도와요 |
| 시술급 리프팅 | 탄탄해 보이는 인상 연출에 도움 |
| 미백(질병 치료식) | 칙칙함 없이 화사한 톤 표현 |

## 3. 콘텐츠 구조 (상세페이지·SNS 기본형)
1. **공감 후크** — 타깃의 고민·상황 한 줄
2. **전환** — "그래서 이런 걸 준비했어요"
3. **제품 핵심** — 콘셉트·핵심 성분 방향(과장 없이)
4. **체험/사용감** — 텍스처·향·발림성 등 감각 묘사
5. **신뢰 요소** — 사용 방법·주의사항·정직한 정보
6. **CTA** — 부드러운 행동 유도

## 4. CTA 예시 (5개 이상)
1. "오늘 내 피부에 한 번 선물해보세요."
2. "지금 내 피부 루틴에 더해보기."
3. "건조함이 신경 쓰였다면, 가볍게 만나보세요."
4. "달라진 사용감, 직접 느껴보세요."
5. "오늘 밤 케어부터 시작해볼까요?"
6. "내 피부에 맞는지 부담 없이 살펴보기."
> 톤: 부드러운 권유형. "지금 안 사면 후회", "마지막 기회" 식 공포·강압 ❌

## 5. 좋은 문장 예시 vs 나쁜 문장 예시
| ✅ 좋은 문장 | ❌ 나쁜 문장 | 이유 |
|-------------|-------------|------|
| "건조해 당기는 피부를 산뜻하게 다독여줘요." | "단 7일 만에 주름이 사라집니다." | 효과 단정·과장 |
| "매끈한 피부 결 표현을 도와줄 수 있어요." | "세포를 재생시켜 피부를 치료합니다." | 의학적 효능 표방 |
| "오늘 하루 지친 피부, 편안하게 쉬게 해주세요." | "이거 안 쓰면 금방 늙어요." | 공포 조장 |
| "순하게 스며들어 부담 없는 사용감." | "부작용 0%, 누구에게나 완벽." | 절대·과장 표현 |

## 6. 대표 문장 (시그니처)
- "피부가 편안해지는 시간."
- "꾸미는 것보다, 돌보는 것."
- "오늘의 나에게, 가장 다정한 한 단계."

## 7. 검수 체크리스트
- [ ] 의료·치료·재생·시술 오인 표현이 없는가 (대체 표현으로 전환했는가)
- [ ] 과장·절대 표현(100%/무조건/부작용 없음)이 없는가
- [ ] 감성 톤 유지(타 브랜드 비즈/서사 톤 혼입 없음)
- [ ] CTA가 압박형이 아닌가
- [ ] 개인정보·결제정보 없는가
