# CHECKLISTS.md — 발행 직전 최종 점검 체크리스트

콘텐츠/산출물을 **외부로 내보내기 직전** 마지막으로 확인하는 체크리스트입니다.
상세 검수는 `06_PROMPTS/review_prompt.md`, 일상 운영은 `daily_operation.md`가 담당하며, 이 문서는 **발행 직전 게이트** 역할입니다.

> 역할 분리: review_prompt(심층 검수) → daily_operation(일일 루틴) → CHECKLISTS(발행 직전 최종 관문)

---

## 1. 공통 발행 게이트 (전 브랜드)
- [ ] 어느 브랜드인지 확정했고, 해당 `BRAND_GRAMMAR.md`를 적용했는가
- [ ] 타 브랜드 톤이 섞이지 않았는가
- [ ] 개인정보·API Key·결제정보·자격증명이 없는가
- [ ] 단정·과장·공포·차별 표현이 없는가
- [ ] 형식이 `.md`/규격에 맞는가, 링크가 깨지지 않았는가
- [ ] `review_prompt.md` 검수에서 "통과"가 나왔는가

## 2. 브랜드별 추가 게이트
**지나스 뷰티**
- [ ] 의료·치료·재생·시술 오인 표현 없음(대체 표현 적용)

**BrandG AI**
- [ ] 보장·과장·buzzword 없음, 효과에 전제 명시, 실단가·계약정보 없음

**운명PT** ⭐ 외부/내부 분리
- [ ] (외부) 사주/운세/점 전면 노출 없음, 일상 고민형 언어, 직접 업셀 없음
- [ ] (내부) 공포 조장·단정 예언 없음, 업셀은 가치 기반
- [ ] 외부/내부 표현이 교차되지 않았는가

**무비지나**
- [ ] 팬덤 존중(비하·성적표현·인신공격 없음), 출처·초상권 확인

## 3. 자동화 발행 시
- [ ] 자동 분류 결과의 브랜드/외부·내부 구분이 정확한가
- [ ] 자격증명이 평문 노출되지 않았는가(자리표시자 유지)

## 4. 게이트 실패 시
- 발행 보류 → 수정 → 재점검. 반복 실패는 `../FAILURE_LOG.md`에 기록.
