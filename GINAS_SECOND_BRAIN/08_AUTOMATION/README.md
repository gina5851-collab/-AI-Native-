# 08_AUTOMATION

## 목적
반복 업무의 **자동화 설계·운영 문서**를 보관합니다.
워크플로우, 자동화 시나리오, 점검 체크리스트를 문서로 관리합니다(코드/시크릿이 아닌 **설계 문서** 중심).

> 🚫 API Key, 토큰, 비밀번호, 웹훅 URL 등 **자격 증명은 절대 저장 금지**.
> 자동화 도구에서 직접 관리하고, 여기에는 "어떤 키가 필요한지"만 자리표시자로 표기합니다.

## 저장할 자료
- `WORKFLOWS.md` — 자동화 흐름 목록(트리거 → 처리 → 결과)
- `PLAYBOOKS/` — 반복 작업 표준 절차서
- `CHECKLISTS.md` — 배포/게시 전 점검 리스트
- `INTEGRATIONS.md` — 연동 서비스 목록(키 값 제외, 용도만 기록)

## 사용 예시
- 콘텐츠 게시 자동화 설계 → `WORKFLOWS.md`에 흐름도 작성
- 반복 업무 표준화 → `PLAYBOOKS/`에 절차 문서화
- 발행 전 점검 → `CHECKLISTS.md` 실행

## 분리 원칙
- 민감정보는 절대 평문 저장하지 않습니다(자리표시자: `<API_KEY_여기에_없음>`).
- 자동화가 다루는 콘텐츠도 브랜드 문법 분리를 준수합니다.
