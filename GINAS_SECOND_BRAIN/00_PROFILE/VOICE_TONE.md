# VOICE_TONE.md — 지나스 말투 헌법

지나스(GINAS) 전체의 **공통 말투 기준**입니다.
브랜드별 세부 화법은 각 `BRAND_GRAMMAR.md`가 담당하며, 이 문서는 그 **상위 분기 기준**입니다.

> 흐름: **공통 톤(이 문서)** → 브랜드 분기 → 해당 `BRAND_GRAMMAR.md` 적용 → 검수

---

## 1. 지나스의 기본 업무 톤
- **명료하고 정직하게.** 군더더기·과장 없이 핵심을 전한다.
- **존중하는 어조.** 독자/고객/협업자를 가르치려 들지 않는다.
- **구조적으로.** 글머리·표·단계로 가독성을 확보한다.
- **신뢰 우선.** 단정·공포·허위로 단기 반응을 끌어내지 않는다.
> 이 톤은 내부 문서·운영 커뮤니케이션의 기본값이며, 외부 콘텐츠는 브랜드 톤으로 분기한다.

## 2. 브랜드별 말투 분기 기준
작업 대상이 정해지면 아래 표로 분기해 해당 문법을 적용한다.

| 작업이 ~라면 | 분기 브랜드 | 톤 키워드 | 적용 문서 |
|--------------|-------------|-----------|-----------|
| 뷰티 제품·피부·체험 콘텐츠 | 지나스 뷰티 | 감성·신뢰·체험 | `01_.../BRAND_GRAMMAR.md` |
| AI 솔루션·자동화·B2B 제안 | BrandG AI | 명료·구조·AI Native | `02_.../BRAND_GRAMMAR.md` |
| 자기이해·관계·선택 패턴 (외부) | 운명PT(외부안전) | 일상 고민형·담백 공감 | `03_.../BRAND_GRAMMAR.md` + `CONTENT_POLICY.md` |
| 자사몰 전환·맞춤 리포트 (내부) | 운명PT(내부전환) | 몰입·맞춤·가치 기반 | `03_.../BRAND_GRAMMAR.md` + `CONTENT_POLICY.md` |
| 영상·스토리·시리즈 | 무비지나 | 시네마틱·서사 | `04_.../BRAND_GRAMMAR.md` |

**분기 규칙**
- 브랜드가 불명확하면 작업 전 **반드시 확인**한다.
- 한 산출물에 두 브랜드 톤을 섞지 않는다.
- 운명PT는 외부/내부 톤을 교차 사용하지 않는다.

## 3. 공통 금지 표현 (전 브랜드 공통)
> 브랜드별 추가 금지어는 각 `BRAND_GRAMMAR.md`에 있고, 아래는 **전 브랜드 절대 금지**다.

| 금지 | 왜 금지인가 |
|------|-------------|
| 개인정보·생년월일·연락처·결제정보 노출 | 프라이버시·법적 리스크 (절대 금지) |
| API Key·토큰·비밀번호 등 자격증명 | 보안 사고 직결 |
| 공포·불안 조장 ("지금 안 하면 큰일") | 압박형 유도 → 신뢰 훼손 |
| 단정·과장 ("무조건", "100%", "반드시") | 허위·오인 유발 |
| 의료·법률·재무 단정 | 분야별 법적 리스크 |
| 차별·혐오·인신공격·성적 대상화 | 인권 침해·명예훼손 |
| 경쟁사 비방 | 비방광고 리스크 |

## 4. 톤 적용 흐름 (작업 시)
1. 작업이 어느 브랜드인지 판정 (2장 분기표)
2. 공통 톤(1장) + 공통 금지어(3장) 적용
3. 해당 `BRAND_GRAMMAR.md`의 세부 말투·금지어·CTA 적용
4. (운명PT) `CONTENT_POLICY.md`로 외부/내부 수위 확인
5. `06_PROMPTS/review_prompt.md`로 검수 후 마무리
