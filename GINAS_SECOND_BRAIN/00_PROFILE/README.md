# 00_PROFILE

## 목적
지나스(GINAS)라는 운영 주체의 **정체성·역할·톤앤매너**를 정의하는 폴더입니다.
모든 브랜드 작업의 기준점이 되며, AI(Claude)가 작업할 때 "지나스가 누구인지"를 참조하는 단일 출처(Single Source of Truth)입니다.

> ⚠️ 개인정보(주민번호, 주소, 전화번호 등), 결제 정보, API Key는 절대 저장하지 않습니다.

## 저장할 자료
- `IDENTITY.md` — 지나스의 한 줄 정의, 핵심 가치, 운영 철학
- `VOICE_TONE.md` — 전체 공통 화법 기준 (브랜드별 세부 화법은 각 브랜드 폴더에서 분리)
- `ROLE_MAP.md` — 사업 영역별 역할(뷰티 / AI / 운명PT / 무비지나 / 개인)
- `STAKEHOLDERS.md` — 협업 대상 유형(실명·연락처 제외, 역할 기준으로만 기록)

## 사용 예시
- "이 카피, 지나스 톤에 맞아?" → `VOICE_TONE.md` 기준으로 검수
- 신규 브랜드/프로젝트 시작 시 → `ROLE_MAP.md`에 역할 추가
- AI 프롬프트 작성 시 → `IDENTITY.md`를 컨텍스트로 주입

## 분리 원칙
- 이 폴더는 **공통 정체성만** 다룹니다.
- 브랜드별 세부 문법은 `01_BRAND_GINAS_BEAUTY`, `02_BRANDG_AI` 등 각 폴더에서 관리합니다.
