# 05_DESIGN_SYSTEM

## 목적
지나스 전체 브랜드의 **시각·표현 일관성**을 관리하는 폴더입니다.
브랜드별로 다른 비주얼 규칙을 한 곳에서 정의하되, **브랜드별 토큰을 분리**해 도메인이 섞이지 않게 합니다.

## 저장할 자료
- `PRINCIPLES.md` — 공통 디자인 원칙(가독성, 접근성, 그리드)
- `TOKENS/` — 브랜드별 디자인 토큰(분리 보관)
  - `ginas_beauty.md`
  - `brandg_ai.md`
  - `fate_pt.md`
  - `movie_gina.md`
- `COMPONENTS.md` — 반복 사용 요소(버튼, 배너, 카드) 표현 규칙
- `TEMPLATES/` — 상세페이지·썸네일·SNS 규격 템플릿

## 사용 예시
- 새 배너 제작 → 해당 브랜드 `TOKENS/`의 컬러·폰트 규칙 적용
- 상세페이지 레이아웃 → `TEMPLATES/`에서 규격 가져오기
- 일관성 점검 → `PRINCIPLES.md` 기준 검수

## 분리 원칙
- 각 브랜드 토큰(컬러·타이포·무드)은 **파일 단위로 분리**합니다.
- 색상 코드·폰트명만 기록하고, 유료 폰트 라이선스 키/계정 정보는 저장하지 않습니다.
