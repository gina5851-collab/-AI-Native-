# Design.md — 지나스 디자인 시스템

브랜드별 시각 언어를 **분리**하여 정의합니다. 한 브랜드의 토큰을 다른 브랜드에 사용하지 않습니다.
(실제 컬러 코드/폰트명은 확정 시 갱신. 아래는 운영 가능한 초안 기준입니다.)

---

## 0. 공통 원칙
- 가독성 우선: 본문 충분한 행간, 모바일 우선 레이아웃.
- 접근성: 텍스트/배경 명도 대비 확보, 색상에만 의존하는 정보 전달 금지.
- 일관성: 같은 요소는 같은 규칙. 신규 요소는 이 문서에 등록 후 사용.

---

## 1. 지나스 뷰티 (GINAS BEAUTY)
- **무드:** 부드럽고 깨끗한, 신뢰감 있는 감성
- **컬러 방향:** 뉴트럴/소프트 톤 (예: 웜 베이지 + 포인트 1색) — *확정 시 HEX 기입*
- **타이포:** 본문 가독형 산세리프 / 제목 감성형
- **이미지:** 피부 질감·자연광 중심, 과도한 보정 지양
- **금지:** 의학적·과장 효능 시각 표현, 자극적 비포&애프터 과장

## 2. BrandG AI
- **무드:** 명료하고 신뢰감 있는 테크 비즈니스
- **컬러 방향:** 딥 뉴트럴 + 액센트 1색 (이성적/정밀) — *확정 시 HEX 기입*
- **타이포:** 구조적 산세리프, 정보 위계 명확
- **이미지/그래픽:** 다이어그램·데이터 시각화 중심
- **금지:** 뷰티 감성 톤·이모지 남용, 모호한 추상 비주얼

## 3. 운명PT (FATE PT)
> 시각 표현도 외부/내부 분리.
- **외부안전(EXTERNAL_SAFE) 비주얼:** 차분·신비롭되 **공포/단정 연출 금지**, 플랫폼 정책 안전
- **내부전환(INTERNAL_CONVERSION) 비주얼:** 자사몰 몰입형, 상품/패키지 시각 강조 가능
- **공통 금지:** 불안 조장 이미지, 차별적·자극적 상징

## 4. 무비지나 (MOVIE GINA)
- **무드:** 시네마틱·서사 중심
- **컬러 방향:** 콘텐츠 세계관별 가변 (시리즈 톤 유지)
- **타이포:** 자막 가독성 + 타이틀 임팩트
- **금지:** 타 브랜드 판매 비주얼 문법 강제 이식

---

## 5. 공통 컴포넌트 규칙
- 버튼/CTA: 브랜드별 액센트 컬러 사용, 행동 동사 명확
- 배너/썸네일: 브랜드별 규격 템플릿(`05_DESIGN_SYSTEM/TEMPLATES/`) 준수
- 카드/목록: 위계(제목>설명>메타) 일관 유지

## 6. 보안
- 컬러 코드·폰트명만 기록. **유료 폰트 라이선스 키·계정·결제 정보 저장 금지.**
