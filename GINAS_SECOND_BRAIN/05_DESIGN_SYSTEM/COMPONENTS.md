# COMPONENTS.md — 공통 컴포넌트 규칙

반복 사용되는 시각 요소의 표현 규칙입니다. 색·폰트 값은 브랜드별 `TOKENS/`를 따릅니다.

> 원칙: `PRINCIPLES.md` · 토큰: `TOKENS/<브랜드>.md`

---

## 1. 버튼 / CTA
- 1차 액션은 브랜드 액센트 컬러, 2차 액션은 뉴트럴.
- 라벨은 **행동 동사 + 대상** ("리포트 받아보기"). 모호어 금지.
- 한 화면 1차 CTA는 1개 권장.
- 톤은 브랜드 `BRAND_GRAMMAR.md`의 CTA 가이드를 따른다(뷰티=권유형, AI=실행형 등).

## 2. 배너 / 썸네일
- 브랜드별 규격 템플릿(`TEMPLATES/`) 준수.
- 핵심 메시지 1개 + 보조 1개까지. 텍스트 과밀 금지.
- 무비지나는 서사 후크, 뷰티는 감성 후크 등 브랜드 톤 유지.

## 3. 카드 / 목록
- 위계: 제목 > 설명 > 메타. 카드 간 간격 일정하게.
- 동일 목록 내 카드 구조 통일.

## 4. 텍스트 블록
- 제목·부제·본문 스타일을 토큰 타이포 스케일로 통일.
- 강조는 굵기/색 중 하나로(중복 강조 지양).

## 5. 폼 / 입력
- 라벨은 항상 표시. 플레이스홀더로 라벨을 대체하지 않는다.
- 에러는 색 + 텍스트로 함께 안내(색 단독 금지).
- 개인정보 입력 안내 시 최소 수집 원칙을 표기(실제 데이터는 문서에 기록 금지).

## 6. 신규 컴포넌트 추가 절차
1. 이 문서에 표현 규칙 등록 → 2. 필요한 토큰 확인/추가 → 3. 사용.
