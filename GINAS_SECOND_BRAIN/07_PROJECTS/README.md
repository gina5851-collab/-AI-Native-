# 07_PROJECTS

## 목적
실행 중인 **프로젝트 단위 작업 공간**입니다.
여러 브랜드를 가로지르는 캠페인·런칭·협업을 프로젝트별로 묶어 관리합니다.

## 저장할 자료
- 프로젝트별 하위 폴더: `YYYY-MM_프로젝트명/`
  - `BRIEF.md` — 목표/범위/기한/관련 브랜드
  - `TASKS.md` — 할 일·진행 상태
  - `ASSETS/` — 산출물 초안
  - `RETRO.md` — 종료 후 회고(→ 인사이트는 09_ARCHIVE로 정리)

## 사용 예시
- 신규 캠페인 시작 → `2026-06_여름런칭/` 생성 후 `BRIEF.md` 작성
- 여러 브랜드 협업 → 프로젝트 폴더에서 통합 관리하되, 산출물은 각 브랜드 문법 준수
- 프로젝트 종료 → `RETRO.md` 작성 후 핵심 자료를 `09_ARCHIVE`로 이관

## 분리 원칙
- 프로젝트는 브랜드를 가로지를 수 있지만, **각 산출물은 해당 브랜드 문법**을 따릅니다.
- 완료/중단 프로젝트는 방치하지 말고 아카이브로 정리합니다.
