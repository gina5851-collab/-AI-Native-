# 06_PROMPTS

## 목적
재사용 가능한 **프롬프트 라이브러리**입니다.
AI 작업의 품질과 일관성을 위해, 브랜드/용도별로 검증된 프롬프트를 분리 보관합니다.

## 저장할 자료
- `_TEMPLATE.md` — 프롬프트 작성 표준 양식(목적/입력/출력/주의사항)
- `beauty/` — 지나스 뷰티 전용 프롬프트
- `brandg_ai/` — BrandG AI 전용 프롬프트
- `fate_pt/` — 운명PT 프롬프트 (외부안전 / 내부전환 하위 구분)
- `movie_gina/` — 무비지나 서사 프롬프트
- `common/` — 공통 유틸 프롬프트(요약, 교정, 번역 등)

## 프롬프트 1개 권장 구조
```
## 목적
## 입력값(변수)
## 프롬프트 본문
## 기대 출력
## 주의/금지사항
## 버전 / 최종수정일
```

## 사용 예시
- 뷰티 상세페이지 생성 → `beauty/`에서 검증된 프롬프트 호출
- 운명PT 외부 게시물 → `fate_pt/`의 안전 콘텐츠 프롬프트 사용
- 프롬프트 개선 시 → 버전·수정일 갱신 후 저장

## 분리 원칙
- 브랜드 문법이 프롬프트에 그대로 반영되므로 **브랜드별 폴더 혼용 금지**.
- 프롬프트 안에 실제 API Key·계정·고객 데이터를 넣지 않습니다(변수 자리표시자만 사용).
