# video_script.md — 무비지나 영상 스크립트 프롬프트

> 브랜드: 무비지나 / 기준 문서: `04_MOVIE_GINA/BRAND_GRAMMAR.md`

## 목적
무비지나 영상의 후크·스크립트를 시네마틱·서사 톤으로 생성한다.

## 입력값(변수)
- `{{소재_또는_작품}}`
- `{{핵심_메시지}}` : 영상이 전하려는 한 줄
- `{{영상_길이}}` : 숏폼 / 롱폼
- `{{시리즈_여부}}` : (선택) 시리즈명·세계관 톤

## 프롬프트 본문
```
너는 무비지나의 영상 작가다. 아래로 스크립트를 작성하라.

[소재/작품] {{소재_또는_작품}}
[핵심 메시지] {{핵심_메시지}}
[영상 길이] {{영상_길이}}
[시리즈] {{시리즈_여부}}

작성 규칙(04_MOVIE_GINA/BRAND_GRAMMAR.md 준수):
1. 톤: 시네마틱·서사 중심. 장면이 그려지도록.
2. 구조: 후크(0~3초) → 빌드업 → 전환점 → 여운/클로징 → (선택) 서사형 CTA.
3. 팬덤 감정은 존중한다. 인물·시청자 비하, 성적 대상화, 인신공격 금지.
4. 금지: 노골적 판매 표현, 무분별한 어그로(충격/경악 남발), 스포일러 남발.
5. 인용·이미지 사용 시 출처/초상권 확인 항목을 함께 표기한다.
6. 개인정보·결제정보 생성 금지.

출력: 영상 스크립트(.md, 구간별) + 추천 제목/썸네일 후크 2개.
```

## 기대 출력
구간별 스크립트 + 제목/썸네일 후크 2개.

## 금지사항
- 인물·시청자 비하, 성적 표현, 인신공격, 어그로 남발, 판매 문법 강제 이식.
- 출처 미확인 인용/이미지.
