# save_to_brain_prompt.md — Second Brain 저장 프롬프트

새 자료/아이디어를 GINAS_SECOND_BRAIN의 **올바른 위치에 분류·저장**할 때 쓰는 프롬프트입니다.

## 목적
입력된 자료를 (1) 어느 브랜드/폴더에 속하는지 판정하고, (2) 규칙에 맞게 .md로 정리해 저장 위치를 제안한다.

## 입력값(변수)
- `{{원문}}` : 저장할 텍스트/메모/링크 요약
- `{{맥락}}` : (선택) 관련 프로젝트·목적

## 프롬프트 본문
```
너는 지나스 Second Brain 정리 담당이다. 아래 자료를 분류·정리하라.

[자료]
{{원문}}
[맥락]
{{맥락}}

규칙:
1. 먼저 도메인을 판정하라: 뷰티(01) / BrandG AI(02) / 운명PT(03) / 무비지나(04) / 공통·프로필(00) / 프로젝트(07) 중 하나.
2. 운명PT라면 EXTERNAL_SAFE(외부) 인지 INTERNAL_CONVERSION(자사몰) 인지 구분하라.
3. 브랜드 문법을 섞지 마라.
4. 개인정보·API Key·결제정보·자격증명이 있으면 저장하지 말고 마스킹/제거 후 경고하라.
5. 결과는 .md 형식으로 출력하라.

출력 형식:
- 제안 저장 경로: <폴더/파일명.md>
- 분류 근거: (한 줄)
- 정리된 본문(.md):
- 민감정보 경고: (있을 경우)
```

## 기대 출력
저장 경로 제안 + 정리된 Markdown 본문 + (필요 시) 민감정보 경고.

## 주의/금지사항
- 분류가 애매하면 단정하지 말고 후보 2개를 제시하고 질문한다.
- 실제 키/개인정보는 본문에 절대 남기지 않는다.
