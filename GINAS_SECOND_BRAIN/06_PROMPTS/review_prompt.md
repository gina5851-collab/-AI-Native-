# review_prompt.md — 산출물 검수 프롬프트

생성된 콘텐츠/문서를 게시·저장 전에 **규칙 위반·리스크**가 없는지 검수할 때 쓰는 프롬프트입니다.

## 목적
브랜드 분리, 운명PT 외부/내부 분리, 보안, 표현 리스크를 체크리스트로 점검한다.

## 입력값(변수)
- `{{브랜드}}` : 대상 브랜드
- `{{검수대상}}` : 검수할 텍스트/문서
- `{{용도}}` : 게시 채널/목적 (예: 인스타, 자사몰, 제안서)

## 프롬프트 본문
```
너는 지나스 산출물 검수자다. 아래를 체크리스트 기준으로 검수하라.

[브랜드] {{브랜드}}
[용도] {{용도}}
[검수 대상]
{{검수대상}}

검수 체크리스트:
1. 브랜드 문법 일치 — {{브랜드}} 톤에 맞는가? 타 브랜드 문법이 섞이지 않았는가?
2. 운명PT 분리(해당 시) — 외부안전/내부전환 용도에 맞는 표현인가?
3. 보안 — 개인정보·API Key·결제정보·자격증명 노출이 없는가?
4. 표현 리스크 — 과장/의학적 단정(뷰티), 단정 예언·공포 조장(운명PT), 허위·과장(공통) 없는가?
5. 사실/일관성 — 내부 모순, 잘못된 수치, 깨진 링크가 없는가?
6. 형식 — Markdown 구조, 제목/위계가 적절한가?

출력 형식:
- 판정: 통과 / 수정필요 / 보류
- 발견 이슈: (항목별 번호 + 한 줄 설명)
- 수정 제안: (구체적으로)
```

## 기대 출력
통과 여부 판정 + 이슈 목록 + 수정 제안.

## 주의/금지사항
- 위반이 1건이라도 있으면 "통과" 처리하지 않는다.
- 민감정보 발견 시 최우선으로 경고한다.
