# CLAUDE.md — 지나스 AI Native 운영체제 작업 지침

이 문서는 Claude(및 모든 AI 협업자)가 `GINAS_SECOND_BRAIN`에서 작업할 때 따라야 하는 **운영 규칙**입니다.
작업 시작 전 항상 이 파일과 `PROJECT_RULE.md`를 먼저 참조합니다.

## 1. 이 저장소의 정체성
- 지나스(GINAS)의 **AI Native 업무 운영체제(Second Brain)**.
- 5개 사업/영역을 분리 운영: 뷰티 · BrandG AI · 운명PT · 무비지나 · 개인업무.
- 모든 자료는 **Markdown(.md)** 으로 관리.

## 2. 절대 규칙 (위반 금지)
1. **브랜드 도메인을 섞지 않는다.** 뷰티 문법 ≠ AI 사업 문법 ≠ 운명PT 문법 ≠ 무비지나 문법.
2. **운명PT는 외부 안전 콘텐츠와 자사몰 내부 전환 콘텐츠를 분리**한다.
3. **개인정보 · API Key · 결제 정보 · 자격 증명은 절대 생성/저장/노출하지 않는다.**
4. 민감정보가 필요한 자리에는 자리표시자만 둔다. 예: `<API_KEY_없음>`.
5. 모든 산출물은 `.md`로 생성한다.

## 3. 작업 순서
1. 파일을 만들기 전에 **작업 계획을 먼저 제시**한다.
2. 어떤 브랜드/폴더에 속하는지 먼저 판정한다(애매하면 질문한다).
3. 해당 폴더의 README와 문법 파일을 기준으로 작성한다.
4. 작업 후 **변경 파일 목록 + 다음 할 일**을 보고한다.
