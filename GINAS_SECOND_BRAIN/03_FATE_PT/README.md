# 03_FATE_PT

## 목적
**운명PT(Fate PT)** 사업 전용 폴더입니다.
운세·사주·관계 등 운명 콘텐츠를 다루며, **외부 플랫폼 노출용**과 **자사몰 내부 전환용** 콘텐츠를 명확히 분리해 운영합니다.

> ⚠️ **핵심 분리 원칙:** 외부 플랫폼은 "안전 콘텐츠", 자사몰은 "전환 콘텐츠"로 이원화합니다.

## 폴더 구조
- `EXTERNAL_SAFE/` — **외부 플랫폼용 안전 콘텐츠**
  - 각 플랫폼 정책·심의를 통과하는 순화된 표현
  - 단정적 예언/불안 조장/의료·법률 단정 표현 금지
  - 목적: 도달·신뢰·유입
- `INTERNAL_CONVERSION/` — **자사몰 내부 전환 콘텐츠**
  - 자사몰 방문 고객 대상 심화 콘텐츠·상품 연결
  - 전환 흐름(CTA, 상품 구성, 패키지) 설계
  - 목적: 전환·재구매

## 저장할 자료
- `CONTENT_POLICY.md` — 외부/내부 표현 기준 비교표 (가장 먼저 참조)
- `EXTERNAL_SAFE/` 내 플랫폼별 콘텐츠 초안
- `INTERNAL_CONVERSION/` 내 전환 시나리오·상세 콘텐츠
- `FUNNEL.md` — 외부 유입 → 자사몰 전환 퍼널 맵

## 사용 예시
- 외부 채널 게시물 작성 → 반드시 `EXTERNAL_SAFE/`에서, 안전 표현 기준 적용
- 자사몰 랜딩/패키지 카피 → `INTERNAL_CONVERSION/`에서 작성
- 신규 콘텐츠 분류 시 → `CONTENT_POLICY.md`로 외부/내부 판정

## 금지 사항
- 외부 콘텐츠에 자사몰 전용 강한 전환 표현/단정 표현 혼입 금지.
- 어떤 콘텐츠도 공포 조장·차별·개인 신상 단정은 사용하지 않습니다.
