# CONTENT_POLICY.md — 운명PT 콘텐츠 표현 정책

운명PT / AI 자기이해 리포트 프로젝트에서 **외부 플랫폼용 안전 콘텐츠**와 **자사몰 내부 전환 콘텐츠**의 표현 수위를 분리 관리하기 위한 정책 문서입니다.
콘텐츠 작성·검수 시 이 문서를 가장 먼저 참조합니다.

> 핵심 원칙: **외부 = 일상 고민형 언어로 신뢰·도달 / 내부 = 전환 설계(단, 공포 조장·단정 예언 금지)**
> 개인정보·생년월일·결제정보 예시는 어떤 경우에도 넣지 않습니다.

---

## 1. 외부 플랫폼용 안전 표현 원칙
- 사주/운세/점 키워드를 **전면에 내세우지 않는다.**
- **일상 고민형 언어**를 우선한다: 자기이해, 선택 패턴, 관계 고민, 돈 관리, 반복되는 선택, 감정 정리.
- 단정적 예언·운명 확정 표현 대신 **자기이해·경향성** 언어 사용.
- 각 플랫폼의 정책·심의를 통과할 수 있는 순화된 표현.
- 목적: 도달·신뢰·유입(자사몰로의 자연스러운 연결).

## 2. 자사몰 내부 전환 문구 원칙
- 이미 관심을 보인 방문자 대상 → **심화 콘텐츠·상품 연결** 가능.
- 감정 트리거 사용 가능하되 **과도한 공포 조장·단정적 예언 금지**.
- 전환 흐름(CTA, 패키지 구성, 혜택 안내)을 명확히.
- 목적: 전환·재구매. 단, 신뢰를 훼손하는 과장은 장기적으로 금지.

---

## 3. 사용 가능한 표현
| 구분 | 사용 가능 표현 |
|------|----------------|
| 외부 | "요즘 반복되는 선택이 고민이라면", "나의 감정·관계 패턴 이해하기", "선택의 기준 정리해보기", "돈 관리 습관 돌아보기" |
| 내부 | "당신의 패턴을 더 깊이 풀어드립니다", "지금 상황에 맞는 맞춤 리포트", "다음 단계로 정리해드릴게요", "한정 구성/혜택 안내" |

## 4. 주의해야 할 표현 (조건부·수위 조절)
- "운세", "사주", "점" → 외부 전면 사용 자제, 내부에서도 맥락 한정 사용.
- "운명", "정해진" → 경향성 언어로 완화 ("~한 경향", "~하기 쉬운").
- 강한 시급성("지금 안 하면") → 내부에서도 과하지 않게, 사실 기반으로.
- 효과 약속("반드시 좋아진다") → 단정 금지, "도움이 될 수 있다" 수준.

## 5. 금지 표현 (외부·내부 공통)
- 단정적 예언/운명 확정: "당신은 곧 ~하게 된다", "~할 운명이다".
- 공포·불안 조장: "지금 안 보면 위험", "큰일 난다".
- 의료·법률·재무 단정: "병이 낫는다", "이 투자는 무조건 오른다".
- 차별·혐오, 특정인 신상 단정.
- 개인정보·생년월일·결제정보를 포함한 예시/유도.

## 6. 사주/운세/점 키워드 사용 기준
| 위치 | 기준 |
|------|------|
| 외부 제목/썸네일 | ❌ 전면 노출 금지 → 일상 고민형 언어로 대체 |
| 외부 본문 | △ 보조적·설명적 맥락에서만 최소 사용 |
| 자사몰 진입 후 | ⭕ 서비스 설명 맥락에서 사용 가능(단정 표현 제외) |

## 7. 감정 트리거 사용 기준
- 외부: **공감 수준**까지만 ("그럴 수 있어요", "많이들 고민해요"). 불안 자극 금지.
- 내부: 동기 부여 수준의 트리거 가능 ("정리하고 나면 한결 가벼워져요"). **공포 조장 금지.**
- 공통 한계선: 두려움을 키워 결제를 유도하는 방식은 금지.

## 8. 업셀 문구 사용 기준
- 외부: 직접적 업셀 금지(자연스러운 유입 유도까지만).
- 내부: 업셀 가능하되 **가치 기반**("더 깊은 분석이 필요하면") — 압박형/공포형 업셀 금지.
- 혜택/구성 안내는 사실에 근거하고, 허위 한정·가짜 시급성 금지.

## 9. 예시 표: 외부용 문장 vs 내부용 문장
| 상황 | 외부 플랫폼용(안전) | 자사몰 내부용(전환) |
|------|---------------------|---------------------|
| 진입 후크 | "요즘 같은 선택이 자꾸 반복된다면?" | "당신의 선택 패턴, 더 깊이 풀어볼까요?" |
| 자기이해 | "내 감정·관계 패턴을 이해해보는 시간" | "당신만의 패턴 리포트로 다음 단계까지" |
| 행동 유도 | "가볍게 한 번 들여다보기" | "지금 맞춤 리포트 받아보기" |
| 가치 제안 | "선택의 기준을 정리하는 데 도움" | "상황별 맞춤 가이드 + 후속 정리 제공" |

## 10. 검수 체크리스트
- [ ] 외부 콘텐츠에 사주/운세/점 키워드가 전면 노출되지 않았는가
- [ ] 외부 콘텐츠가 일상 고민형 언어를 우선했는가
- [ ] 단정적 예언/운명 확정 표현이 없는가
- [ ] 공포·불안 조장 표현이 없는가
- [ ] 의료/법률/재무 단정이 없는가
- [ ] 내부 전환 문구의 감정 트리거가 과도하지 않은가
- [ ] 업셀이 가치 기반이며 압박형이 아닌가
- [ ] 개인정보·생년월일·결제정보 예시가 없는가
- [ ] 외부/내부 표현이 서로 섞이지 않았는가
