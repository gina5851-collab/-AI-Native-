# FUNNEL.md — 운명PT 유입→전환 퍼널 맵

외부 플랫폼 유입부터 자사몰 전환까지의 흐름을 정의합니다.
각 단계의 **콘텐츠 종류·표현 기준·전환 포인트**를 분리 관리합니다.

> 함께 보기: `03_FATE_PT/CONTENT_POLICY.md`(표현 수위) · `BRAND_GRAMMAR.md`(말투)

---

## 1. 퍼널 단계
```
[외부 플랫폼]  도달 → 공감 → 신뢰
     │  (EXTERNAL_SAFE: 일상 고민형, 사주/운세/점 전면 금지)
     ▼
[유입 브릿지]  자사몰로의 자연스러운 이동
     │  (직접 업셀 금지, 가치 기반 안내)
     ▼
[자사몰]  관심 → 맞춤 제안 → 전환 → 재방문
        (INTERNAL_CONVERSION: 감정 트리거 가능, 공포·단정 금지)
```

## 2. 단계별 기준
| 단계 | 위치 | 콘텐츠 | 표현 기준 | 목표 지표(예시) |
|------|------|--------|-----------|------------------|
| 도달 | 외부 | 안전 게시물(`safe_post`) | 일상 고민형, 단정·공포 금지 | 노출·도달 |
| 공감/신뢰 | 외부 | 자기이해 관점 콘텐츠 | 경향성 언어 | 저장·팔로우 |
| 브릿지 | 외부→자사몰 | 가벼운 안내 | 직접 업셀 금지 | 유입 클릭 |
| 전환 | 자사몰 | 전환 카피(`conversion_copy`) | 가치 기반 업셀 | 전환 |
| 재방문 | 자사몰 | 후속 가이드 | 압박 금지 | 재구매 |

## 3. 분리 원칙 (재확인)
- 외부 단계 콘텐츠에 자사몰 전환 표현을 섞지 않는다.
- 자사몰 단계에서도 공포 조장·단정 예언은 금지.
- 브릿지에서 과장된 약속으로 유입을 유도하지 않는다.
