# BRAND_GRAMMAR.md — 운명PT 브랜드 문법

운명PT / AI 자기이해 리포트 전용 화법 규칙입니다.
표현 수위 정책은 `03_FATE_PT/CONTENT_POLICY.md`와 함께 적용합니다.

> 🚫 다른 브랜드 문법과 섞지 않으며, **외부 플랫폼용 / 자사몰 내부 전환용** 문장을 반드시 분리합니다.

---

## 1. 말투 / 톤
- **공감·자기이해 중심.** 판단하지 않고 곁에서 정리해주는 어조.
- 운명을 "정해준다"가 아니라 **"이해하도록 돕는다"**.
- **외부 플랫폼**: 일상 고민형·담백한 공감체. 신비/단정 톤 자제.
- **자사몰 내부**: 몰입형·맞춤형 어조. 동기 부여 가능(공포 조장 제외).

## 2. 금지어 / 금지 표현 + 이유
| 금지 표현 | 왜 금지인가 |
|-----------|-------------|
| "~할 운명이다" / "곧 ~하게 된다" | 단정적 예언 → 오인·신뢰 훼손, 책임 리스크 |
| "지금 안 보면 위험" / "큰일 난다" | 공포·불안 조장 → 압박형 결제 유도(금지) |
| "병이 낫는다" / "이 투자는 오른다" | 의료·재무 단정 → 법적 리스크 |
| "사주" / "운세" / "점" (외부 전면) | 외부 플랫폼 정책·심의 리스크, 거부감 유발 |
| (특정인 신상 단정·차별 표현) | 인권·명예훼손 리스크 |
| 생년월일·개인정보 예시 | 개인정보 노출 → 절대 금지 |

## 3. ⭐ 외부 플랫폼용 vs 자사몰 내부 전환용 (필수 분리)

### 3-1. 외부 플랫폼용 (EXTERNAL_SAFE)
- 원칙: 일상 고민형 언어 우선, 사주/운세/점 전면 노출 금지, 단정·공포 금지, 직접 업셀 금지.
- 좋은 문장:
  - "요즘 비슷한 선택을 자꾸 반복하고 있다면?"
  - "내 감정·관계 패턴을 가볍게 들여다보는 시간."
  - "돈 관리 습관, 한 번 돌아볼까요?"
- 나쁜 문장(외부에서 금지):
  - "당신의 사주를 보면 올해 큰 위기가 옵니다." (사주 전면+공포+단정)
  - "지금 안 보면 운을 놓칩니다." (공포·시급성)

### 3-2. 자사몰 내부 전환용 (INTERNAL_CONVERSION)
- 원칙: 관심 보인 방문자 대상, 감정 트리거 가능(공포·단정 제외), 가치 기반 업셀 가능.
- 좋은 문장:
  - "당신의 선택 패턴, 맞춤 리포트로 더 깊이 정리해드릴게요."
  - "지금 상황에 맞는 분석을 받아보세요."
  - "한 단계 더 깊은 가이드가 필요하다면."
- 나쁜 문장(내부에서도 금지):
  - "이 리포트 안 사면 후회합니다." (공포·압박)
  - "당신은 반드시 헤어지게 됩니다." (단정 예언)

## 4. 콘텐츠 구조
**외부용**: ① 일상 고민 후크 → ② 공감 → ③ 자기이해 관점(경향성 언어) → ④ 가벼운 행동 유도
**내부용**: ① 심화 후크 → ② 맞춤 가치 제안 → ③ 리포트/상품 구성 안내 → ④ 전환 CTA(가치 기반)

## 5. CTA 예시 (5개 이상)
**외부 플랫폼용**
1. "가볍게 한 번 들여다보기."
2. "내 선택 패턴 살펴보기."
3. "오늘의 나, 한 줄로 정리해보기."

**자사몰 내부 전환용**
4. "맞춤 리포트 받아보기."
5. "더 깊은 분석 보기."
6. "내 상황에 맞는 가이드 신청하기."
> 외부=직접 업셀 금지 / 내부=가치 기반(압박형·공포형 금지)

## 6. 대표 문장 (시그니처)
- "정해진 답이 아니라, 나를 이해하는 시간."
- "반복되는 선택에는, 이유가 있어요."
- "운명을 점치기보다, 나를 읽습니다."

## 7. 검수 체크리스트
- [ ] 외부/내부 문장을 올바른 채널에 분리해 사용했는가
- [ ] 외부에 사주/운세/점 전면 노출이 없는가
- [ ] 단정 예언·공포 조장이 없는가
- [ ] 내부 업셀이 가치 기반이며 압박형이 아닌가
- [ ] 개인정보·생년월일·결제정보 예시가 없는가
