# 02_BRANDG_AI

## 목적
**BrandG AI 사업** 전용 폴더입니다.
AI 기반 솔루션·서비스·B2B 제안 등 AI 사업 영역의 자료를 보관하며, 논리적·기술 신뢰 기반의 비즈니스 화법을 사용합니다.

> 🚫 **문법 분리 원칙:** 지나스 뷰티(01)의 감성 화법과 BrandG AI의 비즈니스 화법은 **분리**합니다.
> 뷰티 카피 톤을 AI 제안서에 쓰지 않고, 그 반대도 하지 않습니다.

## 저장할 자료
- `BUSINESS_GRAMMAR.md` — AI 사업 전용 문법(가치 제안 구조, 용어 정의, 톤)
- `SERVICE_CATALOG.md` — 제공 서비스/솔루션 목록과 범위
- `PROPOSALS/` — 제안서·견적 구조 템플릿 (실제 금액/계약 정보는 제외)
- `CASE_STUDIES/` — 사례·성과 요약 (고객 식별정보 제거)
- `POSITIONING.md` — 시장 포지셔닝·경쟁 차별점

## 사용 예시
- B2B 제안서 초안 → `PROPOSALS/` 템플릿 활용
- 서비스 소개 자료 → `BUSINESS_GRAMMAR.md` 기준으로 작성
- 신규 AI 서비스 기획 → `SERVICE_CATALOG.md` 업데이트

## 분리 원칙
- 뷰티 감성 표현·이모지 남용 금지. 명확성·신뢰성 우선.
- API Key, 인증정보, 실제 단가/계약 조건은 **절대 저장 금지**.
