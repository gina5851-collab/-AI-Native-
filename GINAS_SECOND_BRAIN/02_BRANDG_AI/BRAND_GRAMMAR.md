# BRAND_GRAMMAR.md — BrandG AI 브랜드 문법

BrandG AI 사업 전용 화법·표현 규칙입니다.
**AI 조직관리 · 개발자식 운영 · AI Native 문법**을 중심으로 콘텐츠를 작성합니다.

> 🚫 이 문법은 **AI 사업 전용**. 지나스 뷰티(01)의 감성 톤을 가져오지 않습니다.

---

## 1. 말투 / 톤 (AI Native 문법)
- **명료하고 신뢰감 있는 비즈니스체.** 군더더기 없는 단정한 문장.
- **개발자식 운영 언어**: 문제 정의 → 구조화 → 실행 → 검수의 흐름으로 말한다.
- **AI 조직관리 관점**: AI를 "실행자·검수자·정리자" 역할로 다루는 어휘 사용.
- **AI Native 사고**: "사람이 직접" 대신 "시스템/에이전트가 반복 처리"를 전제로 표현.
- 가치·근거·결과 중심. 전문 용어는 **정의를 동반**해 사용.
- 과장 대신 **구체성**(범위·조건·기대 효과)으로 신뢰 확보. 이모지·감탄 최소화.

## 2. 금지어 / 금지 표현 + 이유
| 금지 표현 | 왜 금지인가 |
|-----------|-------------|
| 혁신적 / 세계 최고 / 완벽한 | 근거 없는 최상급 → 신뢰 훼손, 검증 불가 |
| 무조건 성공 / 100% 자동화 | 보장 단정 → 현실의 전제·예외를 숨김 |
| 절대 오류 없음 | AI 시스템 특성상 거짓 → 책임 리스크 |
| 시너지 / 패러다임 (의미 없이 나열) | 공허한 buzzword → 정보량 0, 신뢰 하락 |
| 다정한 / 설레는 (감성어) | 뷰티 톤 혼입 → 도메인 분리 위반 |
| (미검증 수치·실적) | 허위·과장 → 법적·신뢰 리스크 |
| AI가 알아서 다 해줍니다 | 책임 주체 모호 → 운영 원칙(사람=최종판단자) 위반 |

## 3. 콘텐츠 구조 (제안서·서비스 소개 기본형)
1. **문제 정의** — 고객이 겪는 구체적 반복 업무/병목
2. **가치 제안** — 우리가 제공하는 핵심 가치 한 줄
3. **솔루션 개요** — 워크플로우/에이전트 구성·흐름
4. **차별점** — 왜 우리인가(근거·구조 중심)
5. **기대 효과** — 정량/정성 효과(전제 포함)
6. **다음 단계(CTA)** — 명확한 액션

## 4. CTA 예시 (5개 이상)
1. "데모 일정을 잡아보세요."
2. "요구사항을 공유해 주시면 자동화 범위를 제안드립니다."
3. "현재 워크플로우를 진단받아 보세요."
4. "PoC(개념 검증)부터 가볍게 시작해보세요."
5. "도입 상담을 신청하세요."
6. "반복 업무 목록을 보내주시면 우선순위를 설계해드립니다."
> 톤: 명확·실행 지향. 감성 권유·공포·시급성 압박 ❌

## 5. 좋은 문장 예시 vs 나쁜 문장 예시
| ✅ 좋은 문장 | ❌ 나쁜 문장 | 이유 |
|-------------|-------------|------|
| "반복 수작업을 워크플로우로 구조화해 처리 시간을 단축합니다(범위 협의 후 확정)." | "AI로 모든 업무를 100% 자동화해 드립니다." | 보장 단정·전제 누락 |
| "AI는 실행·검수를 맡고, 최종 판단은 담당자가 합니다." | "AI가 알아서 다 처리하니 신경 쓸 필요 없습니다." | 책임 주체 모호, 운영 원칙 위반 |
| "도입 4주 차 기준, 처리 건당 시간이 단축될 것으로 기대됩니다(조건부)." | "도입 즉시 비용이 무조건 절반으로 줄어듭니다." | 미검증·과장 |
| "문제를 정의하면 자동화 범위가 명확해집니다." | "혁신적 패러다임으로 시너지를 창출합니다." | 공허한 buzzword |

## 6. 대표 문장 (시그니처)
- "문제를 정의하면, 자동화는 따라온다."
- "감이 아니라 구조로 일합니다."
- "사람은 판단하고, AI는 실행한다."
- "결과보다 재사용 가능한 시스템을 설계합니다."

## 7. 검수 체크리스트
- [ ] AI Native·개발자식 운영 언어로 작성됐는가
- [ ] 과장·buzzword·보장 단정이 없는가
- [ ] 효과에 전제/조건이 명시됐는가
- [ ] 감성 톤(뷰티 어휘) 혼입이 없는가
- [ ] "사람=최종판단자, AI=실행자" 원칙에 부합하는가
- [ ] API Key·실제 단가·계약정보 없는가
