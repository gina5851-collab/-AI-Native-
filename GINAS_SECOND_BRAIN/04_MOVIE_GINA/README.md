# 04_MOVIE_GINA

## 목적
**무비지나(MOVIE GINA)** 전용 폴더입니다.
영상·영화·스토리텔링 기반 콘텐츠 기획과 제작 자료를 보관합니다. 서사 중심의 창작 화법을 사용합니다.

> 🚫 다른 브랜드(뷰티/AI/운명PT)의 판매 문법을 그대로 가져오지 않습니다. 무비지나는 **콘텐츠/서사** 우선입니다.

## 저장할 자료
- `STORY_GRAMMAR.md` — 무비지나 서사 톤·세계관·내레이션 기준
- `IDEAS/` — 기획 아이디어·로그라인·시놉시스
- `SCRIPTS/` — 영상 스크립트·자막·콘티
- `SERIES/` — 시리즈/시즌별 콘텐츠 기획
- `REFERENCES.md` — 레퍼런스(저작권 출처 표기 필수)

## 사용 예시
- 신규 영상 기획 → `IDEAS/`에 로그라인 작성 후 `SCRIPTS/`로 발전
- 시리즈 톤 통일 → `STORY_GRAMMAR.md` 참조
- 썸네일/제목 후크 → 서사 맥락 유지하며 작성

## 분리 원칙
- 타 브랜드 제품을 영상에 녹일 때도, 무비지나 서사 톤을 우선합니다.
- 저작권·초상권 관련 소재는 출처와 사용 가능 범위를 `REFERENCES.md`에 명시합니다.
