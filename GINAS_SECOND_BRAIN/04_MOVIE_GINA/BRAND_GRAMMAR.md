# BRAND_GRAMMAR.md — 무비지나 브랜드 문법

무비지나(MOVIE GINA) 전용 화법·서사 규칙입니다. 영상·스토리텔링 콘텐츠의 기준입니다.

> 🚫 무비지나는 **서사·콘텐츠 우선**. 다른 브랜드의 판매 문법을 강제로 이식하지 않습니다.

---

## 1. 말투 / 톤
- **시네마틱·서사 중심.** 장면이 그려지도록 쓰는 어조.
- 내레이션은 절제된 호흡. 여운과 리듬을 살린다.
- 정보 나열보다 **장면·감정·전환**으로 끌고 간다.
- **팬덤 감정은 존중한다.** 작품·캐릭터·배우에 대한 애정을 인정하고 공감하는 어조.
- 시리즈 톤은 세계관별로 유지(혼선 금지). 자막은 가독성, 타이틀은 임팩트.

## 2. 금지어 / 금지 표현 + 이유
> 원칙: **팬덤의 애정은 존중하되, 사람을 깎아내리는 표현은 쓰지 않는다.**

| 금지 표현 | 왜 금지인가 |
|-----------|-------------|
| 과도한 인물 비하·외모 비하 | 인신공격 → 명예훼손·혐오 조장, 브랜드 신뢰 훼손 |
| 성적 대상화·선정적 표현 | 플랫폼 정책 위반, 출연자 인권 침해 |
| 특정인 인신공격·악플 인용 | 2차 가해·법적 리스크 |
| 노골적 판매 표현(지금 구매/최저가) | 서사 흐름 파괴, 무비지나 톤 위반 |
| 무분별한 어그로("충격/경악/소름") | 신뢰 하락, 낚시성 콘텐츠화 |
| 출처 없는 인용·이미지 | 저작권·초상권 침해 |
| 차별·혐오 표현 | 사회적·법적 리스크 |
| 스포일러 남발 | 시청 경험 훼손(후킹과 구분) |

## 3. 콘텐츠 구조 (영상 기본형)
1. **후크(0~3초)** — 궁금증·장면 제시
2. **빌드업** — 상황·갈등 전개
3. **전환점** — 반전·핵심 메시지
4. **여운/클로징** — 감정 정리 또는 다음 편 연결
5. **(선택) 행동 유도** — 구독·다음 편 (서사 톤 유지)

## 4. CTA 예시 (5개 이상)
1. "다음 이야기가 궁금하다면, 구독으로 함께해요."
2. "이 시리즈를 끝까지 따라가 볼까요?"
3. "다음 장면은 다음 편에서."
4. "여러분의 해석도 댓글로 들려주세요."
5. "좋았던 장면이 있다면 저장해두세요."
6. "이 캐릭터, 어떻게 느끼셨나요? 함께 이야기해요."
> 톤: 서사 맥락을 깨지 않는 자연스러운 유도. 직접적·반복적 판매 압박 ❌

## 5. 좋은 문장 예시 vs 나쁜 문장 예시
| ✅ 좋은 문장 | ❌ 나쁜 문장 | 이유 |
|-------------|-------------|------|
| "그날의 선택이 모든 걸 바꿔놓았다." | "이거 안 보면 인생 손해, 충격 결말!" | 어그로·과장 낚시 |
| "이 캐릭터를 아끼는 마음, 충분히 이해돼요." | "이 캐릭터 좋아하는 사람들 이해 안 됨." | 팬덤·시청자 비하 |
| "배우의 연기가 장면에 깊이를 더했다." | (출연자 외모·사생활 비하 표현) | 인신공격·대상화 |
| "다음 장면에서 만나요." | "지금 당장 구매 안 하면 손해!" | 판매 문법 강제 이식 |

## 6. 대표 문장 (시그니처)
- "이야기는, 늘 한 장면에서 시작된다."
- "보는 것이 아니라, 머무는 시간."
- "다음 장면에서 만나요."

## 7. 검수 체크리스트
- [ ] 서사 톤 유지(판매 문법 강제 이식 없음)
- [ ] 팬덤 감정을 존중했는가 (비하·인신공격·성적 표현 없음)
- [ ] 어그로/스포일러 남용이 없는가
- [ ] 레퍼런스 출처·초상권이 확인됐는가
- [ ] 개인정보·결제정보 없는가
