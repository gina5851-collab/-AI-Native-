# 09_ARCHIVE

## 목적
완료·보류·폐기된 자료의 **보관소**입니다.
현재 작업 공간을 깔끔하게 유지하기 위해, 더 이상 활성 사용하지 않는 자료를 이곳으로 이관합니다.

## 저장할 자료
- `완료/` — 종료된 프로젝트·캠페인 산출물
- `보류/` — 중단되었지만 재개 가능성이 있는 자료
- `폐기검토/` — 삭제 전 일정 기간 보관
- `INSIGHTS.md` — 아카이브에서 추출한 재사용 가능한 학습 정리

## 사용 예시
- 프로젝트 종료 → `07_PROJECTS`에서 핵심 자료를 `완료/`로 이관
- 시즌 콘텐츠 종료 → 아카이브 후 인사이트만 `INSIGHTS.md`에 요약
- 과거 자료 재활용 → 아카이브에서 검색 후 복원

## 분리 원칙
- 아카이브해도 **브랜드 도메인 구분은 유지**합니다(폴더명에 브랜드 명시 권장).
- 개인정보·민감정보가 포함된 자료는 아카이브 전에 반드시 제거/마스킹합니다.
